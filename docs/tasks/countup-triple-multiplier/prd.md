# PRD: Countup Triple Multiplier

## 概要

Stream Deck の IncrementCounter アクションを改修し、ボタンを押すたびにカウント値が 3 倍になる動作と、長押しによるリセット機能を追加する。

## 対象ファイル

- `src/actions/increment-counter.ts`
- `src/actions/__tests__/increment-counter.test.ts`

---

## 機能要件

### 1. 短押し: 3 倍カウントアップ

| 押下回数 | 表示値 | 計算 |
|---------|--------|------|
| 初期表示 | 1      | -    |
| 1 回目   | 1      | 初回は 1 に設定 |
| 2 回目   | 3      | 1 × 3 |
| 3 回目   | 9      | 3 × 3 |
| 4 回目   | 27     | 9 × 3 |

- `count` が 0（初期状態）のとき: 押下で `count = 1` にセット
- `count` が 1 以上のとき: 押下で `count = count * 3`
- `setSettings` でカウント値を永続化
- `setTitle` でボタンに表示

### 2. 長押し: カウントリセット

- 長押し検出: `onKeyDown` でタイマー開始、`onKeyUp` でタイマーキャンセル
  - 長押し判定閾値: 500ms（SDK にネイティブ長押しイベントがないため手動実装）
- リセット後: `count = 1` にセット（次の短押しで 3 になる）
- リセット直後の表示: `1`
- `setSettings` と `setTitle` でリセット値を即座に反映

### 3. 初期表示

- `onWillAppear`: `count ?? 1` を表示（未設定時は `1`）

---

## ボタン状態遷移

```
[初期表示: 1]
     |
     | 短押し
     v
[カウント表示: 1 → 3 → 9 → 27 → ...]
     |
     | 長押し (500ms 以上)
     v
[リセット表示: 1]
```

### 遷移詳細

| 操作 | 遷移元状態 | 遷移後状態 |
|------|-----------|-----------|
| 短押し (count=0) | 初期 (count=0) | count=1 を表示 |
| 短押し (count≥1) | count=N | count=N×3 を表示 |
| 長押し | 任意のカウント値 | count=1 を表示 |

---

## 非機能要件

- 既存のユニットテストを更新し、新しい挙動をカバーする
- 長押し検出はインスタンス変数でタイマー ID を管理する
- 長押し中に短押しアクション（カウント増加）を実行しない

---

## 変更しないこと

- アクション UUID: `com.hrk-m.kot-punch.increment`
- `manifest.json` の変更なし
- `CounterSettings` 型に `incrementBy` が残る場合は削除可（未使用になるため）
