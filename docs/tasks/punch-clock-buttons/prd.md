# PRD: 出勤・退勤ボタン（punch-clock-buttons）

## 概要

Stream Deck に出勤・退勤の 2 つのボタンを追加する。各ボタンはクリックすると打刻済みを示す ✅ を表示する。

## ユーザーストーリー

- ユーザーとして、Stream Deck の出勤ボタンを押すと出勤打刻が行われ、ボタンに ✅ が表示されることで打刻完了を確認できる
- ユーザーとして、Stream Deck の退勤ボタンを押すと退勤打刻が行われ、ボタンに ✅ が表示されることで打刻完了を確認できる

## 機能要件

### ボタン仕様

| ボタン | 初期表示 | クリック後表示 |
|--------|----------|----------------|
| 出勤   | `出勤`   | `✅`           |
| 退勤   | `退勤`   | `✅`           |

### 動作仕様

1. **初期状態**：Stream Deck に表示された時点でラベル（`出勤` / `退勤`）を表示
2. **クリック時**：ボタンをクリックすると `✅` に表示を切り替える
3. **状態の永続化**：`✅` 表示は Settings に保存し、Stream Deck を再起動してもクリック済み状態を維持する
4. **リセット**：長押し（500ms）で初期ラベルに戻す（打刻取り消し操作として利用）

### アクション定義

- 出勤アクション UUID: `com.hrk-m.kot-punch.clock-in`
- 退勤アクション UUID: `com.hrk-m.kot-punch.clock-out`

## 非機能要件

- 既存の `IncrementCounter` アクションの動作に影響を与えない
- `manifest.json` に両アクションを追記する
- Property Inspector は設定項目なしのため空 body で OK

## 画面遷移

| 状態     | 遷移元         | 操作       | 遷移先状態    |
|----------|----------------|------------|---------------|
| 初期     | ボタン表示時   | —          | ラベル表示    |
| 打刻済み | ラベル表示中   | 短押し     | ✅ 表示       |
| 初期     | 打刻済み       | 長押し     | ラベル表示    |

## スコープ外

- KOT（KingOfTime）API との実際の連携（本 PRD では表示切り替えのみ）
- 出勤・退勤の排他制御（一方を押したらもう一方をリセット等）
